# 🎓 CSIR-CEERI Certificate Verification Webpage

This repository hosts a clean, responsive, and interactive verification webpage for the **Semiconductor High-Impact Learning Program (SHILP)** certificate awarded to **Yogesh Kumar** by **CSIR-CEERI, Pilani**[cite: 1]. Designed primarily as a live portfolio item to embed directly into a B.Tech resume or CV.

---

### 📌 Program Overview
* **Recipient:** Yogesh Kumar (B.Tech, GLA University, Mathura)[cite: 1]
* **Program Name:** SDP Training – Semiconductor High-Impact Learning Program (SHILP)[cite: 1]
* **Issuing Authority:** CSIR - Central Electronics Engineering Research Institute (CEERI), Pilani[cite: 1]
* **Training Period:** June 01, 2026 – June 12, 2026[cite: 1]

---

### 🛠️ Key Features
* **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **Verified Credential Layout:** Professional UI styled with modern CSS CSS variables and typography.
* **Interactive Document Viewer:** Embedded modal viewer to inspect the original PDF certificate[cite: 1] directly on the page.
* **Direct Download Action:** Quick download link for PDF accessibility.

### 🚀 Tech Stack
* **HTML5** – Structured semantic content
* **CSS3** – Custom properties, CSS Grid, Flexbox, & modern styling
* **JavaScript (Vanilla)** – Interactive modal viewer
